# 🏗️ ObraCheck

**Plataforma de acompanhamento e fiscalização de obras públicas em Recife - PE.**

## 📌 Sobre o Projeto

O ObraCheck é um sistema desenvolvido com o objetivo de facilitar o acesso da população às informações relacionadas às obras públicas da cidade do Recife.

A plataforma busca proporcionar mais transparência, permitindo que os cidadãos acompanhem o andamento das obras, consultem informações importantes e tenham maior participação na fiscalização dos investimentos públicos.

## 🎯 Objetivos

- Facilitar o acesso às informações sobre obras públicas.
- Permitir o acompanhamento do andamento das obras.
- Promover a transparência na gestão pública.
- Incentivar a participação da população na fiscalização.
- Centralizar informações relevantes em uma única plataforma.

## ⚙️ Funcionalidades

- Consulta de obras públicas cadastradas.
- Visualização dos detalhes de cada obra.
- Acompanhamento do status e percentual de conclusão.
- Consulta de endereço, datas e órgãos responsáveis.
- Recursos de fiscalização e acompanhamento pela população.

## 🚀 Como Executar o Projeto

### Pré-requisitos

- Java JDK instalado.
- Maven.
- Visual Studio Code ou outra IDE compatível.

### Executando o Backend

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Entre na pasta do projeto:

```bash
cd ObraCheck
```

3. Execute a aplicação:

```bash
./mvnw spring-boot:run
```

No Windows, utilize:

```bash
mvnw.cmd spring-boot:run
```

4. A aplicação poderá ser acessada em:

```text
http://localhost:8080
```
